Pay an agent provider on Solana

Connect a devnet wallet, register a scoped demo agent, and pay through x402 into a per-call escrow. The provider writes a report, signs the delivery, and the verifier settles or slashes. Requires devnet USDC and SOL in the connected wallet.

API unreachable at /api. Start it with `pnpm --filter @attest/api dev`, then reload this page.
