02 / THE GAP

A payment is not
a delivery.

x402 makes machine payments cheap. It does not make them safe. ATTEST adds the missing half: a funded obligation, a bond at risk, a signed proof and a receipt anyone can audit.

01

Fund before work

The exact payment lands in the escrow vault derived from the payer, provider and nonce. The provider can only open the obligation once the vault is funded.

02

Commit the spec

The report spec is hashed before any generation. The provider signs the escrow, spec hash, delivery hash and deadline with one canonical Ed25519 message.

03

Verify objectively

Required sections and minimum length are checked against the committed spec. No vibes, no discretionary settlement: a miss is a slash.

04

Close in public

Settle pays the provider. Slash refunds the payer and charges the bond. Both write an immutable receipt with the verdict and reason code.

03 / THE RECEIPT

Evidence,
not telemetry.

The receipt is a program account. Hashes are reconstructable from the canonical delivery payload; the provider's signature is checked against the escrow's committed spec. Off-chain logs can disappear. This cannot.
