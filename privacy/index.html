Privacy

Last updated: November 2026

What is stored

The API stores agent labels, wallet addresses, hashed API keys, budgets, quotes and the payment-signature index in a local JSON file. Raw API keys are never stored. The web app keeps the demo API key in your browser's local storage.

What is public

Solana accounts and transactions are public. Receipts expose the payer, provider, amount, spec hash, delivery hash and attestation signature. The report text itself is not written on chain; only its hash is. Anyone who has the exact delivery payload can confirm the hash.

Third parties

Payments are verified and settled by the configured x402 facilitator, which receives the signed payment payload and payment requirements. The provider uses a locally configured Ollama endpoint; prompts are not sent to a hosted model by this repository.

Logs

The API redacts authorization headers, API keys, payment payloads and private-key fields from structured logs. Do not enable additional body logging in production.

Contact

This is a reference implementation. For a deployment, publish the operator's contact details and retention policy here.
